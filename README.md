# About Masha 🦋

Интерактивный шуточный React-сайт для подруги Марии.

Несмотря на название проекта `aboutme`, сайт не является портфолио автора и вообще не про меня.

Это небольшой интерактивный профиль, который работает как шуточная «инструкция по эксплуатации Маши» и открывается по QR-коду.

## Идея

Сайт знакомит посетителя с Машей через короткий интерактивный сценарий:

1. шуточная загрузка системы;
2. знакомство с Машей и её фотографией;
3. технические характеристики;
4. интерактивная «комплектация»;
5. небольшой тест на совместимость;
6. итоговый процент совместимости;
7. доступ к контактам только при успешном результате.

Главная идея:

> «Я не сложная. Просто инструкция потерялась.»

А сайт, собственно, и является этой потерянной инструкцией.

## Основные фишки

- mobile-first дизайн;
- адаптация под современные смартфоны;
- тёмная визуальная тема;
- бабочка как фирменный символ;
- интерактивные HUD-элементы;
- анимации появления при скролле;
- шуточные системные сообщения;
- интерактивная секция «Комплектация»;
- тест из 5 вопросов;
- расчёт процента совместимости;
- условная разблокировка соцсетей при результате от 95%.
